Click & conversion measurement

Turned on before publishing. Outbound clicks and the five defined events are measured from the first page view. Everything is privacy-preserving: no cookies, no fingerprinting, no IP storage — only event type, timestamp, page path and a small payload.

The five defined events

EventWhat it recordsPrivacy treatment
page_viewA page is loaded (referrer recorded)Path only; no cookies, no IP, no fingerprinting
outbound_clickA click on a link marked rel="sponsored" (destination URL + link text)Destination and link text only; no personal data
guide_readA buying-guide page is viewedPath only
reader_captureA reader submits the newsletter capture formIntent only; the email is never stored client-side (backend pending)
disclosure_viewThe affiliate disclosure strip is shownNone (impression count only)

Self-hosted endpoint

Events are beaconed (POST JSON) to /analytics/collect. On GitHub Pages — static hosting — that endpoint cannot run server-side, so events fall back to localStorage only and are shown below. Nothing is sent to third parties. When the site moves to hosting that can run the endpoint, the same client code sends to it without changes.
