Open questions

What must be answered before any decision can reasonably be made

Fifteen questions, each with what we already have, what we do not have, the action that closes it, what it blocks, and the default that applies while it stays open. These are also the questions that discover the missing information — every suggestion on the review page maps to one of them.

No question here is rhetorical: each one has an owner action and a safe default. Open a row to read the full record.

Q-01Is the shop one category or two — air fryers only, or air fryers plus meat thermometers?open
What is established
Three submitted links resolve to Air Fryers (17659096011); two resolve to Meat thermometers (289810). All five destinations are live official listings (2026-11-20).
What is missing
The owner's scope decision. Nothing in the repository states which categories the site should cover.
Action that closes it
Pick a path in the chooser on /suggestions/ (Path A, B, or C).
What it blocks
Information architecture, category pages, editorial calendar, internal-link clusters
Default if unanswered
Path B (both categories) — the build covers everything verified; fully reversible

Q-02What is the intended ASIN for each of the five submitted links?open
What is established
All five tokens are 9 characters; Amazon's ASIN definition is 10 characters. Each token's observed redirect destination is recorded in a separate field.
What is missing
intended_asin, intended_listing_url, confirmation_date, intent_source — blank on all five rows; nothing public binds a short code to a product.
Action that closes it
Owner confirms each intended ASIN (or states that the observed destination is the intended one) in data/intent-record.
What it blocks
Closing FLG-006, cross-checking redirects against intent
Default if unanswered
Fields stay blank and flagged; observed values are published as observations only

Related: SG-06 · FLG-006 · FLG-002

Q-03Is tracking ID shopnow047c-20 active, attached to this site, and showing clicks in Associates Reports?open

What is missing

Sign in to Associates → Account → Tracking IDs; confirm status; click one tagged link and check the report.

Links ship with the tag, marked unconfirmed; ledger stays empty

Q-04Do the supplied link.amazon/* short links qualify as Special Links under Operating Agreement §1?open
What is established
§1 requires links to 'properly use the special tagged link formats we provide'. Each supplied token redirects to a live official listing (observed 2026-11-20). The brief says their exact compliance status is unresolved (FLG-003) and forbids claiming they are invalid.
What is missing
Whether the format and domain are Amazon-provided Special Link formats; whether tracking is attributed in reports.
Action that closes it
One-link-per-product test in the enrolled Associates workflow: generate the official Special Link for each ASIN, confirm destination and tracking report, compare with the supplied short link (S02 of the brief).
What it blocks
Scaling any outbound link style (SG-07); full FLG-003 closure
Default if unanswered
Site links use official /dp/ listing URLs + tag + rel="sponsored"; supplied tokens are preserved in the register only
