# Fonts vendored in this directory

The publication loads no third-party font host. Both faces are served from this
repository, so a reader's browser never calls Google Fonts, Adobe, or a CDN.

| File | Family | Source package | Version | License |
|---|---|---|---|---|
| `instrument-serif-latin-400-normal.woff2` | Instrument Serif, regular | `@fontsource/instrument-serif` | 5.3.0 | SIL Open Font License 1.1 |
| `instrument-sans-latin-wght-normal.woff2` | Instrument Sans, variable (weight 400–700) | `@fontsource-variable/instrument-sans` | 5.3.0 | SIL Open Font License 1.1 |

Both are subsets of the Latin range only. Licenses retrieved from the published npm
packages on 2026-11-20; the OFL permits redistribution and self-hosting provided the
license travels with the files, which it does here.

Source for the license text: <https://openfontlicense.org/open-font-license-official-text/>
