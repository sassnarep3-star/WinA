Flagged for Review

Every irregularity, contradiction and unresolved item found while building this site — with its source links. Publishing these is a rule of the project: flagged items never block the site, and they never get quietly "fixed." Review any time and request changes.

Combined register: several parallel sessions worked this repo; the full 51-item register is in data/governance.json and an earlier 23-item view is preserved in the archived build's Flagged page. That register and this page agree on every shared item. The page below prints the items a reader can act on; the register is the complete record, including the ones a later pass re-checked and resolved.

Flags a reader can act on, as of 2026-11-20. Seventeen more are open in the register, most of them owner-side credentials and verification steps; five were resolved by the line-by-line pass on the same date and are recorded rather than deleted.

FLG-001 The five submitted identifiers (e.g. B04G1MEwY) are 9-character tokens. Amazon ASINs are unique 10-character identifiers. The intended identity of each product can't be mechanically proven from the token alone; completing or "correcting" tokens would be inference. Amazon — What is an ASIN? · intent record Owner confirms each intended product against the observed listing (gate G-4), then the intent record's confirmation columns are filled.
FLG-002 Tracking ID shopnow047c-20 is applied to all product links, but no click has been observed in an Associates report. Attribution is unverified until a test click registers; claims about tracking would be unearned. Operating Agreement · gate G-4 Run checklist G-4 (one link per product); record the report evidence in the campaign ledger provenance.
FLG-003 The submitted link.amazon/… short links resolve to real listings, but their compliance status under the Associates agreement is unresolved. Per the brief, we neither claim these links are valid nor invalid — their status is simply open. The OA requires Amazon-provided tagged link formats. Operating Agreement §1 · intent record Table A Ask Associates support whether this format is permitted; until answered, site links use the canonical tagged format.
FLG-004 Chefman TurboFry 8QT listing reads as internally inconsistent on temperature. Reading it end to end on 2026-11-20 resolved it: the bullets give a 200–400°F range and the title names a separate 450°F Hi-Fry option, so they describe different things. The duration of Hi-Fry is the part that was never on this listing — it came from another Chefman SKU (FLG-045). Both statements are on the same official page; silently picking one would misrepresent the source. listing B08DKYBTPH Consult the product manual or manufacturer; until then the comparison table shows both claims as-is.
FLG-005 Product thumbnails are hot-linked from Amazon's media CDN (m.media-amazon.com) rather than sourced through PA-API/SiteStripe. The OA's IP license covers Program Content obtained through program tools; direct hot-linking's coverage is unconfirmed. Operating Agreement (IP license) Proposal S-04: replace with PA-API-sourced images when Associates API access exists (gate G-4).
FLG-006 The Amazon "What is an ASIN?" help URL is real but the page may require Seller Central sign-in to display. Cited for the ASIN definition; readers without a seller account may not see the page. the URL in question Add a login-free mirror citation (e.g. Amazon's public glossary) if one is confirmed.
FLG-007 Chefman dual-basket listing mixes units: title says 6-quart (2 × 3QT) while the product-details row says capacity 6 liters (6 qt ≈ 5.7 L). Same pattern as FLG-004 — a source-internal contradiction, quoted not harmonized. listing B0CDY277D3 Manufacturer spec sheet or manual; the capacity guide currently explains the discrepancy to readers.
FLG-009 Displaying observed prices and ratings outside PA-API may conflict with Associates Program policy: the parallel build's register cites the Program Policies (updated 2026-04-14) §6 as restricting review/rating and price display without API-supplied data, and chose to show no prices at all. This site shows dated, source-linked observed prices/ratings as part of the buyer-research tables. Whether that posture is compliant enough is an owner decision — the conservative alternative is implemented in the archived parallel build. Program Policies · policy.json (verbatim clauses) Owner reads POL-03/POL-04 in policy.json, decides: keep dated snapshots (current site) or suppress prices/ratings (archived build's posture); log the choice as S-14.
FLG-008 The brief referenced "the five defined events" without supplying the canonical list; the measurement spec defines its own five. If the owner has a different canonical list, the events and endpoint allowlist must be renamed to match. measurement spec · analytics.js Owner compares the defined five with any prior spec; approve or replace via Q-15.
FLG-043 Emeril's product page disagrees with itself and with the listing on how many accessories ship: the listing title says six, the manufacturer's own description says seven. The manual names more accessories than the listing does but does not say which are in the box and which are sold separately, so no official page settles the count. emerileveryday.com · listing B09B7SB46R Owner counts the accessories in a box, or asks the manufacturer; the row is published as a claim, not a fact, until then.
FLG-044 Two ThermoMaven specification rows cited a product page that states neither of them. The "auto-rotate bright LED" display and the "1 × AAA, included" battery appear only in customer-review text there, not the manufacturer's copy. Both facts are in the F1 Stealth owner's manual the same page links, so the rows had a citable source all along — the citation was pointing at the wrong page. ThermoMaven HT07 owner's manual Resolved. Both rows now cite the manual: display 0.83 × 1.61 in LED rotating 180°, battery 1 × 1.5 V AAA.
FLG-045 chefman.com's 8-quart page is a different SKU from this listing, and a temperature detail had been taken from it. chefman.com sells RJ38-8T-BLACK at 1700 W; this ASIN's listing states RJ38-SQSS-8T at 1000 W. A reader comparing the two sites will see 1000 W here and 1700 W there. Both are correct for their own SKU, but the figures cannot be mixed, and "Hi-Fry for the final two minutes" is published only on the other SKU's page. chefman.com RJ38-8T-BLACK · listing B08DKYBTPH Recorded so it is not later "fixed" in the wrong direction. The model number is printed beside the figure; changing the number would require a different ASIN, not a different value.
FLG-046 The CHEF iQ Sense model number recorded in the register, CQ60-1C-Z1-E, is the manufacturer's one-probe variant, while this listing is the three-probe Gen3. Attaching a one-probe model code to a three-probe listing would misidentify the item. No page read so far states the three-probe model code. chefiq.com iQ Sense (variant selector: 1 Probe) Field blanked rather than left wrong. Owner reads the code off a three-probe unit or CHEF iQ support, then fills it with that source.
FLG-047 Fourth re-check of the five submitted short links: four landed on the Amazon homepage and one reached its product page — a different split from the two re-checks before it on the same day. The behaviour is not fixed by link, so a single fetch cannot characterise it. Every destination ASIN is separately confirmed by fetching /dp/<ASIN>, so product identity in the intent record stands. No claim is made that the links are invalid. intent record · Program Policies §6(v) Owner opens each link in a normal browser signed out and records the landing URL. Each check is stored as its own dated observation; none is merged into a single value.
FLG-048 CHEF iQ Sense Gen3 warranty: the manufacturer's own user guide states a 2-year limited warranty (activated on first connection to the CHEF iQ App), while retailer listings and third-party mirrors of an older guide state 1 year. The register cannot show both; the buyer-facing figure follows the manufacturer's current official document. The conflict is real and unresolved, so it is flagged rather than silently harmonized. CHEF iQ user guide (official) · chefiq.com Owner opens the CHEF iQ user guide on chefiq.com and confirms the 2-year term applies to the enrolled ASIN; record which document and date governs.
