Campaign ledger

null means not yet obtained. 0 means measured as zero. They are never interchangeable.

Empty by design
datesourcechanneleligible_sessionsclicksitems_addedordersunitscommission_incomeprovenance
empty — 10 columns defined, zero rows—————————

Allowed sources only: Amazon Associates Central > Reports (link clicks, items added, ordered revenue, units) · Amazon Associates Central > Earnings report, exported · Search Console > Performance export (queries, pages, clicks, impressions, position) · The self-hosted event endpoint (page views, impressions, outbound clicks, gate blocks, signups). A row without a provenance value is rejected by the data validator, which is what keeps the empty state empty.

Derived metrics (orders per 100 clicks, EPC) are computed at render time from rows and print a dash while any input is null. See data/campaign-ledger.json.
