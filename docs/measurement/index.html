Measurement

Clicks we can count, conversions we cannot

A short page, because the honest version of affiliate measurement is short: you own the click, Amazon owns the outcome, and the only authorised way to join them is to log into Associates Central and read a report.

no cookie, no localStorage id, no IP retained, no user-agent string stored

Storage is one JSON file per UTC day under a state directory, appended in process and flushed on exit — a design chosen so that "delete the folder" is a complete and verifiable deletion story. Rate limit: 30 events per minute per origin. No secret in the client: the page sends only an event name and a path.

What it deliberately cannot tell you

  • Conversion rate. Orders are reported by Amazon, not by this site, and the 24-hour session window means an on-site model of attribution would be invented.
  • Revenue per page. Earnings are only available at the reporting grain Amazon provides; per-page earnings would be an allocation, not a measurement.
  • Repeat visitors as persons. No cookie, no fingerprint — so a visitor counted twice is a visitor counted twice, and that is the trade for not building a profile.
  • Anything about a reader who blocks scripts. They are simply missing, and the page says so rather than extrapolating.

Run it locally

npm run analytics            # starts on 127.0.0.1:8787
curl -s localhost:8787/healthz
curl -s -X POST localhost:8787/e -H 'content-type: application/json' \
     -d '{"e":"outbound_click","p":"/picks/","l":"prd-01","slot":"shelf"}'
curl -s localhost:8787/summary

Then set config.measurement.endpoint to your host's URL and rebuild: app.js sends beacons only when that value is non-null, so the site can never be quietly measuring somewhere you did not choose.

Queries, the other half

Click counting tells you what a reader did on the page. Only Search Console tells you what they typed, which is the input that should choose the next guide. The pipeline is a file, not a service: export the Performance report into data/exports/gsc-queries.csv and run npm run topics. With no export present the tool prints the manual method and refuses to rank anything — no synthetic demand, ever.
