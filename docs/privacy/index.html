Privacy

What this site stores: nothing

No cookies, no local storage, no third-party scripts, no advertising pixels, no fingerprinting, no email form that works. This page is short because the practice is minimal, and it would grow the day any of that changes.

Reading a page here

  • The HTML, CSS and images are served by GitHub Pages. Requests reach GitHub's servers, and whatever that host records in its own access logs is governed by GitHub, not by this site. See the Pages publishing documentation for how the site is served.
  • This site sets no first-party or third-party cookie and writes nothing to localStorage except, optionally, your own review selections on the suggestion board, which stay in your browser.
  • The search box runs in the page against a static index built with the site. Queries are not transmitted.
  • The calculators take your numbers and multiply them in your browser; the values you type are not sent anywhere.

If measurement is switched on

The event design (/measurement/) is aggregate by day: an event is a name, a path, and a product or slot label. No IP address is retained, no user identifier is created, no Associates reporting identifier is ever joined to a person — the last of which is an Amazon Program Policies requirement, not a preference of ours. If a counting endpoint is deployed later, this page will name the host and the retention rule before the first beacon fires, because a privacy policy written after the fact is a confession.

Email, if it ever happens

The signup block on this site is disabled and states so on its face, because there is no chosen processor, no retention rule and no consent flow yet (FLG-015, Q-10). Nothing is collected, so nothing is stored, and there is nothing to delete on request. That is the honest state of a launch with no form, and it is preferable to a form whose policy is written as a maybe.

Your practical options today

  1. Read the site. Nothing needs your consent, because nothing needs your data.
  2. If you want an item gone from the register (a name, a URL you supplied), open an issue in the repository; the site is built from files in Git, so removal is an edit with a history.
  3. Questions about an order you placed at Amazon do not belong to us and we must not handle them; the contact page explains where they go.
