What the site does by default

  • The site sets no cookies.
  • The page scripts send nothing to any server unless an analytics endpoint has been configured by the operator.
  • Outbound links go directly to Amazon. Amazon's own privacy notice applies on its pages.

Analytics, if turned on

If the operator sets an analytics endpoint, the site can send five events: a page view, an outbound product click, a guide read, a disclosure expansion, and an RSS feed click. Each event carries only the fields listed on the analytics page.

The site never sends an IP address, user agent, cookie, full referrer, query string, or form input. The collector stores only daily counts.

Amazon's requirements

The Associates Participation Requirements require a site to disclose its use of cookies, pixels, and similar technologies accurately, and to say how visitors can opt out where the law requires it (SRC-02, §3(e)).
