What was verified, line by line

Every factual row on this site traces to a line in this table. Where a value could not be confirmed from an official source, it is blank on the page and named below — the two states are never merged, and a gap is never filled with a likely number.

How each row was checked

  1. Locate the document on the publisher's own domain — no aggregator, no screenshot, no blog paraphrase.
  2. Read the page body and copy the clause that carries the obligation, so the quote is checkable against the page rather than against a summary.
  3. Record the page's own revision date when it shows one, and the date it was read.
  4. Note the read level honestly: a full page read is not the same as text matched from an official-domain excerpt, and the column says which it is.
  5. Re-check before anything is quoted to a reader; the gate flags any row older than 90 days.

Re-run the register check: npm run check:data · refresh quotes against the live pages: node tools/compliance-gate.mjs --refresh-sources
