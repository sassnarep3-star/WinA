Marketing kit

Ready-to-use copy for all five products, written under the same rules as the site: no invented prices, no claimed testing, disclosure travelling with every post.

The marketing plan on the previous page says where the traffic should come from. This page is the copy that goes into it. Each entry is short on purpose — a hook, a social post, a newsletter paragraph — and every one of them carries the Associate statement, because a disclosure that lives only on the site does not cover a post that leaves it.

The five rules this copy obeys

  1. No price, no star rating, no review count. Amazon prohibits displaying them outside approved tooling, and a price in a social post goes stale in a week.
  2. No testing claim. Nobody here used these machines, so no post says 'we tried' or 'our favourite'.
  3. Every post carries the disclosure. On a platform with no visible footer, that means in the text, not behind a link.
  4. The claim in the copy is the claim in the register. If the register says unverified, the copy does not say it.
  5. Link to the review page, not straight to Amazon, unless the platform makes the tag impossible to attach — then use the tagged link and say it is sponsored in the same breath.

Each block is written to be pasted as-is. Bracketed links point at the review page on this site, not at Amazon, so the reader meets the disclosure before the buy button.

Before anything is published

  1. Does the post carry the Associate statement in the visible text?
  2. Is every number in the post a number the register supports?
  3. Would the post still be true if the price doubled tomorrow? If not, it is a price post — cut it.
  4. Does the link go to the review page, and is the review page's own disclosure above the fold?
  5. Is there any implied endorsement by Amazon or the manufacturer? There must not be.

If a post fails the third question, it is a price post. Those go stale and, under the Program Policies, they are not ours to publish in the first place.
