What would close the gap

Three actions unlock almost everything else on this page. None of them can be done by a code session: each needs the account holder.

  1. 1

    Confirm the Associates account is enrolled, active and earning under shopnow047c-20

    Without this, every link on the site may be earning nothing and no question about commission, rates or reporting can be answered. It closes Q-04 and unlocks Q-26.

    How: sign in to Associates Central, open Account Settings, and confirm the tracking ID and account status. Record the date on the register.

  2. 2

    Register the site in Search Console

    This is the only lawful way to see which queries actually reach the site, and the only way to find out whether any archived page was indexed before it was disallowed. It closes Q-07, Q-18 and Q-23, and it is the input the topic roadmap is waiting on.

    How: verify the property (the DNS or HTML-file method both work on Pages), then export Performance > Queries after two weeks. Drop the export into data/exports/ and run npm run topics.

  3. 3

    Deploy the self-hosted collector and set a lawful-basis line

    Nothing is measured today. Five events are defined and the collector is written, but no endpoint is set, so the client drops events on purpose rather than pretending. This closes Q-16 and Q-27 and makes every later layout decision testable.

    How: host _worker/collector.js on a runtime with a request log, set site.analyticsEndpoint in data/products.json, rebuild, and confirm one page_view arrives.
