Search and findability

One site for search engines to index, a stated reason to rank it, and an honest account of what is still unverified.

One canonical site

Everything published here lives under a single origin with a single sitemap. There is no duplicate staging site, no competing subdomain, and no second copy of the same guide in a different folder. Every page declares a canonical URL, so even if a page is reachable through more than one path, search engines are told which one counts.

The site is a static build with no client-side routing, so every URL is a real document that returns a real HTML page. Crawlers do not need to execute JavaScript to see the content — what you read is what is in the source.

What is in place

  • A sitemap listing every public page with a last-modified date, referenced from robots.txt.
  • An RSS feed carrying the guides, so the publication has a subscribable surface from day one.
  • Per-page titles and descriptions written for a human deciding whether to click, not stuffed with keywords.
  • Structured data where it is honest to use it: Article on guides, ItemList on category pages, WebSite on the front page.
  • Semantic HTML — one h1 per page, real headings, real lists, real tables with captions and scoped headers.
  • Fast by construction — no framework, no web font request, no third-party script. The page is the document.

Why it deserves to rank

Not because of technical tricks — those are table stakes and everyone has them. The reason is that each guide answers a question in a way the competing pages do not: it gives the reader a decision procedure instead of a verdict, and it says plainly when the recommended product is wrong for them.

It also refuses to fabricate. No invented prices, no borrowed star ratings, no claimed testing. On a topic where most pages are generated and interchangeable, a page that is specific about trade-offs and honest about its limits has something no amount of keyword optimisation can imitate.

What is not verified

Search Console ownership has not been confirmed, because that requires account access. A placeholder verification token is in the markup and clearly marked as such.

Until that is replaced, this site has no idea whether it is indexed, what it ranks for, or whether anyone arrives. It is the single highest-value five-minute task remaining, and it is recorded as an open action rather than described as done.

No search volume data exists for any of the guide topics. The titles are editorial hypotheses about what people might ask, not evidence about what they do ask. Publishing the guides and reading the query report is how that changes.

What we will not do

No buying of Amazon trademarks as search keywords, whether through ads or any other mechanism — that is prohibited and would risk the account. No keyword-stuffed doorway pages. No spinning one article into twenty near-duplicate variants to chase long-tail queries; it works briefly and then gets the whole domain discounted. No cloaking the destination of a product link.

The build enforces part of this mechanically: a page cannot publish without a unique title and description, and the validation step fails if any outbound Amazon link is missing its sponsored marking.
