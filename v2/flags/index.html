Prices were observed on every listing on 2026-11-20. None are printed here. Amazon's Program Policies allow a site to show price and availability only when Amazon serves the link containing that data, or when the data comes from the Creators API / PA API. This site is static and uses neither.

Impact Readers must click through to see a price. That is the compliant behaviour, not an omission.

Status by design — needs review

To close Obtain PA API / Creators API access, then render price from an API response with the required attribution.
