Method

How this site is built, and what it refuses to do

The rules below are not aspirations. A build script checks most of them on every deploy and fails the deploy if one breaks.

The five rules

  1. One source per fact. Every specification links to the page it came from. If there is no page, the cell says “Not confirmed”.
  2. Contradictions are printed, not resolved. When a listing disagrees with itself, the site shows both figures. See the flagged page for three live examples.
  3. No price, ever. Amazon's terms restrict price display to data Amazon supplies. A static site cannot comply, so it does not print price.
  4. No invented experience. Nothing here claims hands-on testing, because nothing has been tested by hand.
  5. Disclosure above the fold, on every page. Not buried, not only on a legal page.

What the build checks automatically

On every push, a verification script reads the generated HTML and fails if any of these are false:

  • The disclosure strip appears on every page, before the main content.
  • The disclosure is repeated in every footer.
  • Every link to amazon.com carries rel="sponsored nofollow noopener".
  • No price literal appears anywhere in the output.
  • Every page has a canonical URL on a single host.
  • The sitemap lists exactly the pages that exist, and nothing else.
  • Every spec table row carries a source link or an explicit “Not confirmed”.

What a human has to check

Three things cannot be automated, and are logged instead:

  • Whether the tracking ID is actually enrolled and crediting clicks.
  • Whether a specification still matches the live listing (it will drift).
  • Whether the editorial voice is still honest — the machine can check that a source exists, not that the sentence using it is fair.

All three appear in the open questions register with the specific action that closes them.

Editorial voice

The site writes about trade-offs rather than winners. Where a product is worse at something, the page says so in the same breath as what it is good at. Where two products are genuinely interchangeable for a reader, the page says that too, instead of manufacturing a distinction to justify a recommendation.
