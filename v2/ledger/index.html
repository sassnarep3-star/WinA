Definitions fixed in advance

eligible_session
A session in which the page rendered and the disclosure strip entered the viewport at least once. Establishes that the reader had the opportunity to see the material connection.
outbound_click
A click on a link carrying rel="sponsored" that resolves to an amazon.com destination.
reported_order
A shipped order as counted in an Amazon Associates report for this tag. Not a page view, not an add-to-cart, not our own estimate.
channel
The referral source: organic, direct, rss, social, or unknown.
source
The page path the session started on.

Why it is empty

Two things are missing and both are logged: there is no analytics endpoint (FLG-006) because GitHub Pages cannot execute server code, and no Associates report has been pulled (FLG-010).

The event layer that will feed the sessions and clicks columns is already written and shipped — disabled, with five defined events. Choosing an endpoint is SG-02.
