Decision queue · 12 proposals

Suggestions, waiting for a decision

This section exists so that nothing gets implemented before someone chooses a path. Each proposal names the problem, the evidence, the options, the cost and what it gets you. Nothing below has been built.

How to use this page. Work top to bottom. Priority is the order to decide, not the order to build — SG-01 costs one click and invalidates five other items if it comes back negative. Pick an option letter, and that is the whole review.

SG-01 · priority 0

Confirm the tag before anything else

Every link on this site may be earning nothing. We cannot tell from the outside.

Evidence All five short links resolved to the correct ASINs but none exposed a tag= parameter. FLG-003 / Q02 / Q03.

PathCostWhat it gets you
a · Test one link in the enrolled workflow1 click + 48h waitConfirms or refutes attribution for all five.
b · Regenerate all links with a visible tag15 minMakes attribution auditable and removes the ambiguity permanently.
c · Leave the short links as supplied0Keeps the current uncertainty. Risk: all traffic earns nothing.

Recommended a, then b. The test is nearly free and settles a question that invalidates every other effort on this page.

Answer first: Q01, Q02, Q03, Q04

Evidence assets/analytics.js ships disabled with no endpoint. Q09. FLG-006.

PathCostWhat it gets you
